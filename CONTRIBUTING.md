# Contributing

Thanks for helping improve KM Digital Labs Accountant.

## Good contributions

- Reproducible bug fixes
- Accessibility and mobile-layout improvements
- Clearer bookkeeping documentation
- Tests or validation for accounting calculations
- Small, focused interface improvements

## Workflow

1. Open an issue describing the problem or choose an existing issue.
2. Fork the repository and create a descriptive branch.
3. Keep the change focused and avoid committing personal financial data.
4. Test transaction entry, navigation, backup/restore and affected reports locally.
5. Open a pull request describing the behaviour before and after your change.

Do not include API keys, customer records, exported backups or confidential business information.
