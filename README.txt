KM DIGITAL LABS ACCOUNTANT
Local Accounting, Journals, Payroll and Financial Statements

WHAT IT DOES
- Records every receipt, payment, transfer and manual journal entry
- Produces receipt journals and payment journals automatically
- Tracks employee and contractor payments
- Maintains a chart of accounts and general ledger
- Generates trial balances, profit and loss statements and balance sheets
- Creates transaction receipts that can be saved as PDF
- Saves financial statements as PDF
- Exports JSON backups and transaction CSV files
- Works without Supabase, login, APIs or monthly fees

HOW TO USE
1. Extract the ZIP.
2. Open index.html in Chrome or Edge.
3. Open Settings & Backup and complete the KM Digital Labs information.
4. Record money received or money paid.
5. Use Financial Statements to generate and print reports.

HOME-SCREEN APP
Upload the complete folder to InfinityFree or another HTTPS host.
Open the hosted page in Safari or Chrome and choose Add to Home Screen / Install App.
The supplied KM Digital Labs K-square is used as the home-screen icon.

DATA STORAGE
Records are stored in localStorage on the current browser.
They do not automatically sync across devices.
Use Export JSON Backup, transfer the file, then import it on another device.

ACCOUNTING LOGIC
Every transaction contains one debit account and one credit account for the same amount.
The trial balance checks whether debit and credit balances agree.
The balance sheet includes current accumulated profit or loss in equity.

SAVING PDF STATEMENTS
Open Financial Statements, choose a report and dates, then click Save PDF.
The system PDF window opens with an automatic filename. Select Save as PDF.

IMPORTANT
This application is designed for internal bookkeeping.
Back up records regularly and have formal financial or tax submissions reviewed where required.
